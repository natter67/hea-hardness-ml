# Data

`MPEA_dataset.csv` — mechanical properties and observed phases of multi-principal element alloys.

* **Source:** <https://github.com/CitrineInformatics/MPEA_dataset>, commit
  `d31e2510cccc3fb9e79d43ad62652f64ef8c2c5e` (SHA-256 of the file:
  `c5504d93fd324d1be26cf814d0694ee9ee95578d68a0b38aba6813b939fa2c5d`).
* **Paper:** C. K. H. Borg et al., "Expanded dataset of mechanical properties and observed phases
  of multi-principal element alloys", *Scientific Data* 7, 430 (2020).
  <https://doi.org/10.1038/s41597-020-00768-9>
* **License:** Apache-2.0 (as declared in the source repository). Unmodified copy.

Re-download / verify with `python scripts/download_data.py`.

The file is small (~330 kB), so it is committed for convenience; the download script is the
canonical way to obtain it.
